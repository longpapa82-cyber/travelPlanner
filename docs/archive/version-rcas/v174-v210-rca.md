## V199 핵심 수정 (2026-04-28) — phantom 구독 9차 근본 해결

**RCA**: webhook 비동기성으로 server DB tier는 구조적으로 stale 가능. "server-authoritative" 원칙이 webhook 신뢰성에 기반하므로 webhook race/누락/dedup 우회 시 DB는 거짓말.

**Alpha 2건 (V198)**:
- Bug 1: DB=free지만 RC에 yearly active → monthly 결제 허용
- Bug 2: 탈퇴→재가입 후 연간/월간 전체 차단

**수정**:
- RevenueCatClient 신설 (`revenuecat.client.ts` — RC REST API, 3s timeout, fail-close)
- preflightPurchase dual-source (Layer 1: DB tier → Layer 2: RC active_entitlements)
- cross-SKU block (yearly active → monthly도 차단)
- auto-reconcile (DB free + RC active → DB=premium 자동 복구 + audit log)
- 메시지 분기 (reason enum 3가지)
- fail-close (RC API 장애 시 차단)
- degraded mode (REVENUECAT_API_KEY 미설정 시 DB-only fallback)
- 불변식 50~54 신설
